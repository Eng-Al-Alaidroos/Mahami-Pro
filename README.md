# مِهامي Pro

نسخة أولية لتطبيق أندرويد عربي لإدارة المهام مع تخزين محلي SQLite.

## الميزات الحالية
- واجهة عربية RTL.
- إضافة وتعديل وحذف المهام.
- البحث حسب العنوان والملاحظات والإدارة المستفيدة.
- الأولوية والحالة والموعد النهائي.
- تخزين محلي لا يتطلب اتصالًا دائمًا بالإنترنت.

## بناء APK
بعد رفع الملفات إلى فرع `main`، افتح تبويب Actions واختر `Build Android APK`. بعد اكتمال البناء بنجاح، نزّل artifact باسم `mahamipro-release-apk`.

التوقيع اليدوي وتقارير PDF والتذكيرات والإدخال الصوتي العربي ميزات مخطط لها للمراحل التالية.
